# 🎬 Movie Recommendation System

An end-to-end movie recommendation system built using **NLP, TF-IDF, FastAPI, and Streamlit**.

### Features
- 🔎 Movie search using TMDB
- 🎯 TF-IDF-based content recommendations
- 🎭 Genre-based recommendations
- ⚡ FastAPI backend
- 🎨 Streamlit frontend

### Tech Stack
**Python • FastAPI • Streamlit • Scikit-learn • NLP • TF-IDF • TMDB API**
